# Game Dev Refresh

A Unity project created as part of my game development refresh process.

## About

This repository contains a 2D gameplay prototype focused on rebuilding and improving my Unity and C# skills through hands-on development.

The project currently includes movement mechanics, jumping systems, wall interactions, checkpoints, respawning, and gameplay feedback systems.

## Features

- 2D character movement
- Ground jump, wall jump, and air jump
- Coyote time and jump buffering
- Wall hanging
- Fast fall
- Checkpoint system
- Respawn system
- Checkpoint activation feedback

## Tech Stack

- Unity 6 (6000.6.0f1)
- C#
- Unity Input System
- Rigidbody2D / 2D Physics
- Animator

## Project Status

Active development / learning prototype.

The current focus is on building small gameplay systems, improving code structure, testing mechanics, and gradually increasing development independence.

## Goals

- Strengthen Unity and C# fundamentals
- Practice gameplay architecture and state management
- Build reusable gameplay systems
- Improve debugging and testing habits
- Create portfolio-ready gameplay projects

## Repository Structure

- `Assets/` - Game assets, scripts, scenes, animations, and project content
- `Packages/` - Unity package configuration
- `ProjectSettings/` - Unity project settings
